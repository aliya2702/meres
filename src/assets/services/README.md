# Services Showcase Image Slots

Drop optional concept visualization images for the **Bathrooms** and **Additions & custom homes** service stages into this folder. Vite detects them automatically without any code edits.

## Expected Files

- `bathroom.(jpg|jpeg|png|webp)` — landscape `16:9`, at least `1672px` wide
- `additions.(jpg|jpeg|png|webp)` — landscape `16:9`, at least `1672px` wide

While a file is absent, the showcase renders the green-to-taupe tonal fallback with the MERES mark and omits the `"Concept visualization"` caption.
